# Vyapar Desk

A mobile-first, frontend-only workspace for Indian small businesses.

## Features

- Today’s sales, collections, dues, and low-stock overview
- GST-ready invoice creation
- WhatsApp invoice sharing
- Local stock adjustments and product search
- Payment collection and customer dues tracking
- GST sales summary and CSV-ready ledger
- Local persistence in the browser

## Run locally

```bash
npm install
npm run dev
```

## Checks

```bash
npm test
npm run build
```

This app is frontend-only and does not call an AI or ad network.

## Monetization path

For a real launch, use the placeholders as layout-reserved ad inventory and add only network scripts
you are approved to use. A practical sequence is:

1. Add consent and privacy controls before activating analytics or personalized advertising.
2. Enable one banner and one in-content ad format after approval from the ad network.
3. Add contextual, clearly disclosed affiliate tools for finance and shopping only where relevant.
4. Introduce a small premium tier for ad-free use, saved calculations, PDF exports, and higher AI limits.
5. Offer sponsored calculators or comparison modules only with prominent sponsor disclosure.
